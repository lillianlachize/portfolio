🌐 R1 - Fondamentaux Réseaux et Systèmes

👨‍🏫 Enseignant : M. REZZAG A./p>

Coefficient :4
📝 Modalité :TP + Examen pratique

📖 Vue d'ensemble

R1 - Fondamentaux Réseaux et Systèmes pose les bases essentielles de l'administration systèmes et réseaux. Module crucial pour SISR.

🎯 Objectifs

  • Comprendre les fondamentaux du modèle TCP/IP
  • Configurer des systèmes Windows et Linux
  • Administrer des services réseau de base (DHCP, DNS)
  • Mettre en œuvre la virtualisation
  • Diagnostiquer les problèmes réseau et système

📚 Programme

  1. Architecture réseaux : Modèle OSI, TCP/IP, adressage IPv4/IPv6
  2. Systèmes d'exploitation : Windows Server, Linux (Debian, Ubuntu)
  3. Services réseau : DHCP, DNS, Active Directory
  4. Virtualisation : VMware, VirtualBox, Hyper-V
  5. Diagnostic : Wireshark, ping, traceroute, netstat

⚠️ Points d'attention

Important : Pratiquez en laboratoire régulièrement. L'examen pratique nécessite une maîtrise des commandes et configurations.
